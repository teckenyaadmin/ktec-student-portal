## What this starter includes
- Responsive landing page for phones, tablets and computers.
- Navy, white and gold visual identity.
- Pricing and service descriptions.
- WhatsApp links with pre-filled service enquiries.
- Searchable 18-item cluster guide.
- Contact email and official KUCCPS/HEF links.
- Independence and official-results disclaimer.

## Important: this is a foundation, not a finished production portal
The current cluster guide is an introductory navigation list, not a calculator. It does not calculate official KUCCPS weighted cluster points or determine admission eligibility. Official programme requirements and results must be verified against current KUCCPS information.

Not yet implemented: student authentication, student records, admin dashboard, verified course/institution database, PDF report generation, email automation, M-Pesa payments, payment verification, and service request tracking. These require secure backend configuration and testing before collecting student data or accepting payments online.

## Run locally
Requires Node.js 20 or later.

```bash
npm install
npm run dev
```
Open http://localhost:3000.

## Deploy
This is a Next.js application. Connect this GitHub repository to Netlify and configure the build using the Next.js runtime/build settings recommended by Netlify. Do not upload secrets or `.env.local` to GitHub.

## Privacy and trust
KTEC is an independent education guidance service and is not KUCCPS, HELB, HEF, KNEC or a government agency. Confirm official application requirements, deadlines, placements and funding decisions with the relevant official institutions.
